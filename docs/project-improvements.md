## 동작 범위

- 등록 자료의 승인율은 세목별 필수 서류 충족률이 아닙니다. 필수 자료는 담당자가 별도로 확인합니다.
- `Matter.evidenceCoverage`는 등록 자료 승인율이고 `AgentRun.evidenceCoverage`는 분석 근거 검증률입니다. API 호환성을 위해 필드명을 유지하고 UI에서 의미를 구분합니다.
- 미해결 쟁점 수를 계산하는 별도 도메인 모델은 없습니다. 미평가를 0으로 바꾸지 않습니다.
- AI는 현재 질문만 실행합니다. 화면의 이전 대화는 모델 문맥에 자동으로 포함되지 않습니다.
- 감사 내보내기는 검색 결과 전체를 대상으로 하며 10,000건 초과 시 날짜/검색 조건 축소를 요청합니다. 조용히 일부 행을 누락하지 않습니다.
- 데모 업로드는 실제 워커 처리를 수행하지 않습니다. 상태 조회 창을 닫거나 페이지를 이동하면 브라우저의 조회만 중단됩니다.
- 페이지 기반 조회는 전체 목록 전송량을 제한합니다. 실제 고객 규모의 부하와 쿼리 지연은 별도 측정 대상입니다.

## 실행 결과

`npm run verify`(포맷, 린트, 타입 3종, 단위 테스트 129개, AI 평가 45개와 프로덕션 빌드), macOS Chromium 35개 테스트와 운영 의존성 감사(취약점 0건)가 통과했습니다. 브라우저 전체 검사는 기준선 갱신 옵션 없이 다시 실행했습니다. 실제 PostgreSQL 마이그레이션과 DB 계약 31개도 통과했습니다. Linux Chromium에서도 화면 3종의 접근성과 시각 회귀를 추가로 검증했습니다. 실모델 호출, 공개 배포, 실제 모바일 기기와 운영 IdP 연결은 이번 검증 범위에 포함하지 않았습니다.

Linux 화면 검증은 Ubuntu 기반 Playwright 컨테이너의 Chromium에서 수행합니다. 로컬 Colima의 `host.lima.internal` 경유 개발 리소스 요청은 `E2E_RESET_ENABLED=true`인 테스트 모드에서만 추가로 허용합니다. 기본 개발 모드와 운영 설정에는 이 호스트를 추가하지 않습니다.
