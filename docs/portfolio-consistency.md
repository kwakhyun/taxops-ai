# 자료와 구현의 버전별 변경 기록 - 2026-09-05

설계 문서, 시연 영상과 실모델 평가 기록을 현재 구현과 대조합니다. 승인 권한 분리, 비동기 파일 처리, 모바일 업무 흐름의 설계는 유지하며 화면 구성, 지표와 검증 개수의 변경을 구분합니다.

## 버전 기준

- [9월 5일 기능 개선 전 코드](https://github.com/kwakhyun/taxops-ai/tree/9a7ff3206564656faaddb4c1c605ea1df4204308)는 2026-09-01 커밋 `9a7ff32`입니다.

- 문구 정리 전 자료는 Git 이력의 [커밋 `dc83255`](https://github.com/kwakhyun/taxops-ai/tree/dc83255bcf4f6d6faa73e2f439cbb94f6f9ee7ad)에서 확인할 수 있습니다.

신고 점검과 지표 수정은 설계 문서에 서술된 승인 경계를 화면에서도 정확히 반영하기 위한 보완입니다. 영상의 파일 등록은 처리 완료를 뜻하지 않으며, 미리 등록된 예시 조서로 승인하는 흐름이라는 기존 설명도 유지합니다.

최신 검증 수치는 [README](../README.md#검증-결과), 구체적인 수정과 제한은 [프로젝트 개선 기록](project-improvements.md)을 기준으로 확인합니다. 변경 가능한 `main` 링크와 공개 데모는 최신 구현을 보여 줄 수 있으므로, 이전 버전 자료와 비교할 때는 위 고정 링크를 사용합니다.
