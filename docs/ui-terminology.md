# 화면 문구 기준

검토일: 2026-08-31. 홈, 업무 목록과 등록, 개별 업무, 자료 관리, AI 파트너, 검토 및 승인, 운영 현황, AI 품질 평가, 감사 로그의 제목, 상태, 버튼, 도움말과 오류 안내를 대상으로 한다.

## 세무 용어와 제품 용어 구분

- `매입세액 불공제`는 국세청의 [사업용 신용카드 안내](https://b.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7799&mi=2475)에서도 사용하는 표현이다. 일반 업무 안내에서는 유지한다.
- 신고서 항목이나 서식명을 직접 지칭할 때에는 국세청 [세무서식 목록](https://b.nts.go.kr/nts/ad/nf/nltFormatApiList.do?mi=40178&searchSe=select&selectCode=type10&selectLawNm=%EB%B6%80%EA%B0%80%EA%B0%80%EC%B9%98%EC%84%B8%EB%B2%95)의 `공제받지 못할 매입세액 명세서` 등 공식 명칭을 따른다. 인용 원문과 기존 파일명을 문체 통일을 위해 임의 수정하지 않는다.
- `근거 사용 승인`, `근거 충족률`, `검색용 문서 구간`은 TaxOps AI의 제품 용어이며 법령 용어가 아니다. 문서 구간 수와 근거 사용 승인율을 구분해, 내용 처리가 끝났다는 이유만으로 해당 자료가 AI 검색에 사용된다고 안내하지 않는다.
- `검토조서`는 이 플랫폼에서 검토자의 확인과 승인을 받는 내부 업무 산출물이다. 세무 신고서나 법정 제출서류와 동일한 문서로 표현하지 않는다.

## 표현 원칙

| 의미                     | 사용 표현                                | 피하는 표현                |
| ------------------------ | ---------------------------------------- | -------------------------- |
| 검토 후 다음 행동        | 검토 의견 반영                           | 검토 의견 해소             |
| 업무 진행 표시           | 세무 업무 진행 단계                      | 세무 업무 진행 구조        |
| 조직 단위 자료 접근 제한 | 자료 조회 범위 / 현재 조직의 자료만 조회 | 데이터 경계                |
| 전체 업무의 우선순위     | 우선 확인할 업무 / 업무 상태 요약        | 통제 항목 / 업무 신호      |
| 분석을 위한 자료 분할    | 검색용 문서 구간 / 문서 구간 수          | 문맥 없이 표시한 검색 단위 |
| 신고 이전 준비 상태      | 신고 전 최종 점검                        | 제출·사후 준비             |

여섯 단계는 `업무 개요 → 자료 수집 → 근거 검토 → 계산 및 초안 → 검토 및 승인 → 신고 및 사후 관리`로 표시한다. 이는 탐색과 준비 상태를 안내하는 정보구조이며, 홈택스 자동 신고 기능을 제공한다는 뜻이 아니다.

## 기능 범위를 정확히 안내

- AI는 근거 검색과 계산뿐 아니라 검토조서 초안 작성도 지원하며, 최종 판단과 승인은 검토자가 수행한다.
- 감사 기록은 해시 체인으로 연결해 변경 여부를 검증한다. 해시 체인 자체를 모든 수정과 삭제를 물리적으로 막는 장치로 설명하지 않는다. 데이터베이스의 변경 차단 정책은 별도로 구분한다.
- AI 품질 화면의 통과 여부는 저장된 평가 보고서의 사례와 기준에 대한 결과다. 전체 코드의 배포 적합성이나 실제 세무 정확성을 보증하는 표현은 사용하지 않는다.
- 관리자 화면에는 추적 ID, 토큰, 검색 재현율 등 필요한 기술 용어를 유지하되, 일반 업무 화면에서는 사용자의 행동과 결과를 먼저 설명한다.

## 상태와 지표 해석

- **근거 사용 승인율**: 등록 자료 중 색인 완료와 근거 사용 승인을 모두 충족한 비율입니다. 대시보드의 평균은 진행 중인 업무별 승인율의 단순 평균입니다.
- **등록 자료 처리·승인**: 등록된 자료의 처리 상태이며 세목별 필수 서류 충족을 뜻하지 않습니다.
- **근거 기반 분석 완료**: 최신 분석의 독립 검증 단계와 근거 검증률 100%를 확인합니다. 실행 ID만 존재하거나 분석에 실패한 상태는 완료로 표시하지 않습니다.
- **전문가 검토·승인 완료**: 검증된 최신 분석과 연결된 조서가 승인된 상태입니다.
- **미평가**: 미해결 쟁점 수를 아직 평가하지 않은 상태입니다. 0건과 구분합니다.
- **고객사, 세목, 화면 검색**: 업무와 화면 이동용 검색입니다. 문서 본문 검색을 의미하지 않습니다.
